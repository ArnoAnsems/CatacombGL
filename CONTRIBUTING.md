# Submitting patches

Patches may be submitted via a pull request on GitHub. All new contributions must be licensed as GPLv3 or later. If importing third-party code, it must be under a GPL-compatible license.

## Use of Generative AI, including LLMs

Submitted code shall not be made by Generative AI. Code made with Generative AI may possibly be derived from sources with unclear terms of use, hence it is important submitted code is written by contributors directly.

Contributors are expected to be able to answer questions about the submitted pull requests on their own.

Pull requests, including textual descriptions, shall be created by contributors, without using Generative AI.

Note that the automation of tasks (e.g., text editing) is allowed if not done with Generative AI at all, but the rest of the requirements still apply.
